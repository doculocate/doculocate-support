Running locally

Start the app from source and understand configuration and deployment limits.

Checked against the app · September 27, 2026

On this page
RequirementsStart a local instanceConfigurationDeployment boundaries

Requirements

Use the DocuLocate application repository, not this support-site repository. The app declares Node.js 18.17 or later. The first semantic search may need network access to download its model.

Start a local instance

# Run from the DocuLocate application directory.
npm install
HOST=127.0.0.1 APP_MODE=local npm run dev

Open http://localhost:4100/. Explicitly setting HOST keeps this instance bound to your own machine. The current server code otherwise defaults to 0.0.0.0.

For a compiled build:

npm run build
HOST=127.0.0.1 APP_MODE=local npm start

Configuration

VariableBehavior
HOSTListen address. Set 127.0.0.1 for access only from the local machine.
PORTDefault 4100.
APP_MODEUse local (the default). Hosted is not implemented.
MAX_DOCUMENTSPositive integer; default 50. Oldest files are evicted over capacity.
Provider keysOptional. See AI reranking.

Set these variables in the process environment or with your own environment loader. Merely creating a .env file is not a guarantee that the server will read it.

Deployment boundaries

The current app has one in-memory document store and no built-in authentication. A server restart clears documents, and hosted mode does not yet supply persistence or private workspaces. Local mode describes the implementation; it does not by itself restrict network access.

For Docker, follow the application's Dockerfile and Makefile. Review the published port binding before running a container; binding the host port to loopback limits access to the local machine.
