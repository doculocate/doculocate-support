Optional AI reranking

How optional providers reorder results, handle quotes, and use document text.

Checked against the app · September 27, 2026

On this page

Search works without an API key

The application runs a small semantic search model on the server that hosts DocuLocate. On a local installation, that is your machine. The model downloads on first use and is cached for subsequent use. Base retrieval does not send document text to a remote AI provider.

What reranking adds

When a provider key is configured, DocuLocate sends the search query and up to 20 candidate passages to that provider to improve their ordering. It may also return a supporting quote for the top result. This is still passage retrieval, not document chat.

Configure a provider

The operator sets a provider key in the application's process environment and restarts the server. There is no per-user key-management screen. Never include keys in a support issue or client-side code.

PriorityProviderEnvironment variable
1AnthropicANTHROPIC_API_KEY
2OpenAIOPENAI_API_KEY
3GeminiGEMINI_API_KEY
4GroqGROQ_API_KEY
5OpenRouterOPENROUTER_API_KEY

The first configured key in this order wins. Configure only the provider you intend to use. Provider charges and data policies apply.

If reranking is unavailable

A provider failure falls back to the base similarity results. The API reports reranked: false. A successful reranking pass reports reranked: true, and the app shows “Reranked by AI.”

To disable external reranking, remove all configured provider keys from the server environment and restart it. Restarting also clears the in-memory document collection.
