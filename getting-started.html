Getting started

Your first search

DocuLocate finds passages inside documents by meaning. You enter a search; it returns ranked excerpts from the original files. It does not generate a chat answer.

  1. Open your DocuLocate app. For a locally running instance, the default address is http://localhost:4100/.
  2. Choose Add documents. Select files or drag them into the upload area. Wait for the files to appear under Your collection.
  3. Describe what you need. For example: situations where the customer can cancel without paying a fee.
  4. Click Search or press Enter. Read the ranked passages and their relevance labels.
  5. Choose View in document. Inspect the original file and surrounding context before relying on a result.

Search your collection

The app searches every document currently uploaded to the running instance. You can add several files at once; the browser uploads them one at a time. The API also lets you restrict a search to selected document IDs.

Remove a document

Use the × button beside a file in Your collection. This removes the document and its cached search data from the running application. Your original file on your computer is unchanged.

A temporary workspace

Documents are held in server memory. A server restart clears the collection. The default capacity is 50 documents; adding more evicts the oldest. There are no separate user accounts or private workspaces in the current version.
