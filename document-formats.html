Documents & formats

Supported files, upload limits, scanned PDFs, and document locations.

Supported formats

FormatExtensionsLocation in results
PDF.pdfPage number
Word.docxSource passage
Plain text.txtSource passage
Markdown.md, .mdxHeading, where available
HTML.html, .htmSource passage

Legacy Word .doc, spreadsheets, CSV, JSON, and XML are not advertised as supported formats. Save relevant content as a supported text format if appropriate, then check that the conversion preserved what you need.

File and collection limits

  • Maximum upload size: 25 MiB per file (26,214,400 bytes).
  • The upload API accepts one file per request. The app sends multiple selected files sequentially.
  • The default collection limit is 50 documents, configurable by the operator using MAX_DOCUMENTS.
  • When the collection exceeds its limit, the oldest documents are removed from the application store.

Scanned or image-only PDFs

The current PDF parser extracts embedded text; it does not run optical character recognition (OCR). An image-only scan can return “contains no extractable text.” Use an OCR tool to create a searchable PDF first, and verify the extracted text before uploading it.

Why some results have no page or section

Location details depend on the parser. PDF results can show page numbers, and Markdown can show headings. DOCX, HTML, and plain text currently return source passages without page or section metadata. A missing location does not mean the passage was generated.

Opening the original

View in document returns the uploaded file. A PDF link includes the page number for compatible browser PDF viewers. Other formats may download or open in another application depending on your browser. DocuLocate does not provide an embedded editor for every format.
