Help us reproduce the problem

Use the DocuLocate support repository to report app bugs, ask usage questions, or suggest improvements.

Create a GitHub issue ↗ Browse existing issues

What to include

  • The steps you took and what you expected.
  • What actually happened, including a sanitized error message.
  • The app version or commit, operating system, browser, and Node.js version if running locally.
  • File format and approximate size; whether a PDF contains selectable text.
  • Whether optional AI reranking was enabled, and which provider (never its key).
  • A small, fictional sample that reproduces the issue, if possible.
Check before you post

Treat GitHub issues as public. Remove credentials, customer documents, private file names, personal information, and internal addresses. Describe security concerns without publishing exploit details or sensitive material in an ordinary issue.

Suggest an improvement

Explain the task you want to complete, what currently gets in the way, and an example of the desired behavior. For a new file format, include the extension and the kind of content you need to search.

Before opening a report

Review troubleshooting and search existing issues. This support site does not promise a response time or a paid support plan.
