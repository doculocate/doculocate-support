An upload fails

Error or symptomWhat to try
no_fileSelect a file. API clients should send multipart form data with a file field.
unsupported_formatCheck the supported extensions. Renaming an unsupported file does not convert it.
parse_failedCheck that the file opens in its native application. Try re-exporting it, removing password protection where authorized, or using a small sample.
empty_documentThe parser found no extractable text. A scanned PDF may need OCR first.
File too large / HTTP 413Reduce the file below 25 MiB or split it into smaller documents.
HTTP 429Pause requests and retry. The current server rate limit is 200 requests per minute per client IP by default.

No relevant passages appear

  1. Confirm the document appears in Your collection.
  2. Check that it has selectable, extractable text.
  3. Try a shorter search with one concept and fewer conditions.
  4. Inspect the original document directly. Search is not an exhaustive proof of absence.

The first search is slow or times out

The first search loads the semantic model, which may require downloading model files. Initial document processing also creates cached search data. Check network access for the model download and available system resources. If the message says the local embedding model timed out loading, retry the search. If it continues, include the sanitized error and environment in a report.

My documents disappeared

The document store lasts only for the server process lifetime. A restart clears it. Exceeding the configured collection capacity removes the oldest documents. A shared instance also allows other users with access to remove documents. Re-upload your original files if needed.

View in document downloads a file

This can be expected for DOCX and other formats your browser does not display. Open the downloaded original in an appropriate application. PDF page jumps depend on your browser's PDF viewer.

Hosted mode will not start

APP_MODE=hosted is scaffolding and currently fails at startup. Use APP_MODE=local. Setting database variables does not enable accounts or persistent storage.

Common questions

Is this a chatbot?

No. DocuLocate returns ranked source passages. It does not synthesize conversational answers.

Do I need a paid AI API key?

No key is needed for base search. External reranking is optional and subject to your provider's charges.

Can I search more than one document?

Yes. The app searches the uploaded collection. API clients can provide documentIds to search a subset.

Does it search spreadsheets or scanned images?

Spreadsheets are not currently supported, and PDF extraction does not include OCR. See the document-format guide.
