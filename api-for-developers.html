API for developers

Upload documents and retrieve source passages with the REST API.

Connect to your instance

Examples use the default local address http://localhost:4100. Replace it with your configured instance address. The current local implementation has no built-in authentication; keep access restricted appropriately.

Open /docs on your app instance for the generated interactive API reference.

Endpoints

Method and pathPurpose
POST /v1/documentsUpload one document as multipart form data
GET /v1/documentsList documents, newest first
DELETE /v1/documents/:idRemove a document and its search cache
GET /v1/documents/:id/fileRetrieve the original file
POST /v1/searchReturn ranked source passages
GET /v1/healthReturn a basic health response

1. Upload a document

curl -sS http://localhost:4100/v1/documents \
  -F 'file=@agreement.pdf;type=application/pdf'

The response includes id, name, format, mimeType, sizeBytes, and createdAt. Save the returned ID if you want to limit searches or remove the document. One file per request; maximum 25 MiB.

2. Search for a concept

curl -sS http://localhost:4100/v1/search \
  -H 'Content-Type: application/json' \
  -d '{"query":"cancel without paying a fee","limit":5}'
FieldRules
queryRequired string, 1–500 characters
documentIdsOptional array of IDs; omitted or empty searches all documents
limitOptional integer, 1–50; default 10

Unknown request fields are not allowed by the schema. Document IDs that no longer exist are ignored.

Read the response

The response contains query, results, and reranked. Each result has:

  • documentId, documentName, and format
  • score and relevance (high, medium, or low)
  • location: page, heading, or an empty object
  • snippet: source text
  • highlight: a checked source quote or null

No generated answer field is returned. Escape source text before rendering it in HTML. If highlight is null, display the passage without a quote highlight. Reranking can change order without changing the base similarity scores.

Manage the collection

curl -sS http://localhost:4100/v1/documents

# Replace DOCUMENT_ID with an ID returned by the upload or list API.
curl -i -X DELETE http://localhost:4100/v1/documents/DOCUMENT_ID

Deletion returns HTTP 204 on success or 404 if the ID is missing. Original-file requests return file bytes, not JSON; an unknown ID returns 404. Review upload and request errors for troubleshooting.
